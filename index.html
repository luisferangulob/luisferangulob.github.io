02 / RESEARCH

Modeling biological structure through computation.

My current research focuses on computational models of three-dimensional root architecture and the large-scale analysis of simulated biological structures.

The project combines stochastic modeling, geometry, simulation, and high-performance computing to explore how local growth rules generate complex root systems.

Stochastic three-dimensional root architecture generated by the simulation framework.

Featured Research

3D Root Architecture Simulation

Computational Plant Science Laboratory · University of Arizona

I develop a stochastic computational framework for generating and analyzing three-dimensional root systems from local growth rules.

The simulator uses local coordinate systems, quaternion-based transformations, branching, self-avoidance, and Monte Carlo simulation to generate complex root geometries across thousands of parameter configurations.

The resulting structures are summarized through more than one hundred quantitative measurements, creating a large-scale dataset for studying how model parameters influence root architecture.

Interactive Scientific Application

Root Architecture Visualizer

↗

Interactive exploration of simulated root geometry, parameters, metrics, and statistical structure.

An interactive analysis environment for exploring, comparing, and clustering simulated 3D root architectures.

The application turns simulation outputs into an interface for inspecting individual root geometries, parameter configurations, and quantitative structural measurements.

I am extending the app with PCA-based architecture analysis to study similarity across high-dimensional root measurements and identify groups of quantitatively related architectures.

Cluster exploration connects numerical structure back to geometry by loading real simulated roots nearest the PCA cluster centers, rather than creating artificial centroid root structures.
